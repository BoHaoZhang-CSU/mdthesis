# 模板放在这里

本仓库**不附带 Word 模板** —— 模板是需要自行准备的资产。

## 放置

把你的 `.docx` 模板放进这个目录，然后加工一次：

```bash
python3 tools/prepare_template.py 你的模板.docx 你的模板_pandoc.docx
```

加工会做四件事（都能自动完成，但都需要模板本身）：

1. 给 `heading 2` 加段前分页 —— 让每章另起一页
2. 把表格样式的 styleId 对齐成 `Table` —— 否则三线表的线渲染不出来
3. 调整标题的大纲级别 —— 让自动生成的目录层级正确
4. 剥掉模板自带的图片 —— 否则每次转换都会被塞进输出

加工完直接转换即可，默认会用它：

```bash
./tools/convert.sh 你的文档.md 输出.docx
```

## 如果暂时没有模板

`tests/regression.sh` 和 `tests/api_smoke.sh` 在找不到模板时，
会用 **pandoc 自带的 reference 模板**临时生成一份中性的来跑测试
（生成物在 `tests/.out/.demo/`，不会进仓库）。
这样 clone 下来就能验证功能是否正常，只是拿不到特定模板的版式。

## 什么样的模板能用

- 必须有 **`heading 2`** 样式（章节用）—— 没有的话加工会直接报错并提示
- 章节样式的大纲级别建议设对（Word 里「段落 → 大纲级别」），
  这样即使样式名是自定义的（如「一级标题」）也能被自动识别
- 其余样式（大标题、摘要、目录标题）缺了会自动从内置默认补齐
